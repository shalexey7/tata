# TATA — сайт-визитка мастерской

Кроватки-машинки и толокары из берёзовой фанеры.

Статический сайт: только HTML, CSS и один JS-файл. Никаких сборщиков, Node и
зависимостей — что лежит в папке, то и уезжает на хостинг.

```
tata/
├── index.html        ← вся страница: экраны, тексты, разделы
├── css/style.css     ← оформление (палитра — в переменных в самом верху файла)
├── js/app.js         ← товары, контакты и механика каталога
├── images/           ← картинки товаров и первого экрана
├── favicon.svg       ← иконка вкладки
└── README.md
```

## Как посмотреть локально

Достаточно дважды кликнуть по `index.html` — сайт откроется в браузере.
Если хочется «как на настоящем сервере»:

```bash
cd ~/Desktop/projects/tata
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Как добавить товар

Всё в файле `js/app.js`, массив `PRODUCTS`. Копируете любой блок и правите:

```js
{
  id: 'krovat-gonka',                // латиницей, без пробелов — попадает в ссылку
  title: 'Кровать «Гонка»',
  category: 'Кроватки',              // по категориям сами собираются кнопки-фильтры
  price: 33900,
  badge: 'новинка',                  // подпись на картинке; '' — без подписи
  inStock: true,                     // false → «под заказ», кнопка меняется
  image: 'images/krovat-gonka.jpg',
  desc: 'Короткое описание в карточке.',
  props: [
    ['Спальное место', '160 × 80 см'],
    ['Материал', 'берёзовая фанера ФК, 18 мм'],
    ['Возраст', 'от 3 лет'],
  ],
},
```
Категория новая? Ничего дополнительно делать не нужно — кнопка фильтра появится сама.

## Как поменять контакты

Там же, `js/app.js`, объект `CONFIG` в самом верху. Оттуда берутся и блок
«Связаться с нами», и кнопка «Заказать» (она открывает Telegram или WhatsApp
с уже набранным текстом заказа). Пустая строка = блок не показывается.

## Как заменить картинки

В `images/` сейчас лежат **нарисованные заглушки** — чтобы сайт выглядел цельным
до фотосъёмки. Кладёте свои фото туда же и прописываете имя файла в поле `image`
товара. Рекомендации:

- карточка квадратная, так что и фото — квадратные, около 1000 × 1000 px;
- снимать лучше на однотонном светлом фоне, изделие целиком, с одного ракурса —
  тогда каталог выглядит как каталог, а не как лента;
- формат JPG или WebP, вес до ~300 КБ на фото;
- имена файлов — латиницей, без пробелов.

Отдельно: `images/og.png` — картинка-превью, её видно, когда ссылку на сайт
кидают в мессенджер. Замените на фото или на баннер 1200 × 1200 px.

## Как опубликовать на GitHub Pages

```bash
cd ~/Desktop/projects/tata
git add -A && git commit -m "Обновление сайта"
git push
```

Первая публикация: создать пустой репозиторий на своём GitHub (без README),
затем:

```bash
git remote add origin git@github.com:ВАШ_ЛОГИН/tata.git
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Source: Deploy from a branch →
`main` / `/ (root)` → Save**. Через пару минут сайт будет доступен по адресу
`https://ВАШ_ЛОГИН.github.io/tata/`.

### Свой домен

1. Положить в корень файл `CNAME` с одной строкой — вашим доменом.
2. У регистратора домена добавить CNAME-запись на `ВАШ_ЛОГИН.github.io`.
3. В Settings → Pages включить **Enforce HTTPS** (сертификат GitHub выпустит сам).

## Мелочи, о которых легко забыть

- **Кеш браузера.** Ссылки на CSS и JS в `index.html` идут с меткой версии
  (`?v=20260918`). Поменяли стили или скрипт — поменяйте и дату в обеих ссылках,
  иначе у посетителей неделю может висеть старая версия.
- **Тексты страницы** (первый экран, «О магазине», доставка) правятся прямо в
  `index.html` — это обычный текст между тегами.
- **Заголовок вкладки и описание для поисковиков** — теги `<title>` и
  `<meta name="description">` в начале `index.html`.
